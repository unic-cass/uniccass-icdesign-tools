# OpenIC IC Design Tools

---

The **OpenIC IC Design Tools** repository is a fork of the *UNIC-CASS IC Design Tools* repository which has been customized to work with OpenIC Design Flow. For details on the UNIC-CASS repository, click [here](https://github.com/unic-cass/uniccass-icdesign-tools/tree/release/1.3.0).

We welcome contributions from the global IC design community!
