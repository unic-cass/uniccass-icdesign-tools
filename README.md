# OpenIC IC Design Tools

[![License: Apache 2.0](https://img.shields.io/badge/License-Apache2.0-lightgrey.svg?style=flat-square)](LICENSE)

---

The **OpenIC IC Design Tools** repository is a fork of the *UNIC-CASS IC Design Tools* repository which has been customized to work with OpenIC Design Flow. For details on the UNIC-CASS repository, click [here](https://github.com/unic-cass/uniccass-icdesign-tools/tree/release/1.0.7).

We welcome contributions from the global IC design community!

## Supported OS
* Linux
* Windows (via WSL 2)
* macOS (not verified)
